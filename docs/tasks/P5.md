Handed over mid-way because the session budget ran out. Everything below "What exists" is done and tested; "Pending" is
what is left, in priority order.

## What exists
- **Speech to text** (`babas/stt.py`, `Session` handler, `Settings.stt_*`, `BABAS_STT_*`, `docs/providers.md` section 4):
  `chat` (Gemini through the OpenAI-compatible endpoint), `whisper` (`/audio/transcriptions`), `local` (faster-whisper,
  extra `stt`). The LLM key/model are only inherited when the speech endpoint is the LLM endpoint (review SEC-0 fixed);
  75 s overall deadline; `stt_status(settings)` tells whether a backend is configured.
- **Side panel voice** (`extension/src/sidepanel/voice.ts`, `view.ts`, `model.ts`, `background/voice-relay.ts`,
  `micpermission.html`): "Hablar" -> "Terminar"/"Cancelar grabacion", 16 kHz WAV, silence auto-stop, transcript only fills
  the box, mic unavailable while a card is open, permission tab for browsers whose side panel shows no prompt.
- **Terminal UI** (`babas/ui.py`, dependency free) applied to the CLI, `serve`, `pair`, `ConsoleChannel`; preview with
  `python -m babas.ui`. CLI voice (`babas_listen.py`) goes through `babas.stt`.
- **Tests**: `tests/test_stt.py`, `tests/test_session.py`, `tests/test_ui.py`, `tests/test_listen.py`,
  `tests/e2e/test_voice_e2e.py` (real Chromium with a fake microphone), extension vitest suites.
- Also fixed on the way: the extension opened two bridge sockets at install ("Sin conexion" in the panel).
