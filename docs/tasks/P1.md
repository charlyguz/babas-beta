# P1 — BrowserDriver + WebSocket bridge + minimal extension

Goal: `babas.py` becomes the `babas/` package (`python -m babas`) with an async `BrowserDriver` interface and two
implementations: `PlaywrightDriver` (today's behavior) and `ExtensionDriver` (WebSocket → MV3 extension). `python -m
babas serve --repl` lets a developer list, highlight, click and type on a real page through the extension. The LLM
never drives the extension in P1, because the safety layer arrives in P2.

Read first: `CLAUDE.md`, `docs/PROTOCOL.md` §1–2, `docs/SAFETY.md` §2.

Async rules:
- Use `playwright.async_api` (`async_playwright`, `Page`, `BrowserContext`, `Browser`).
- `await` every Playwright call that acts or returns data: `goto`, `click`, `fill`, `press`, `inner_text`,
  `get_attribute`, `is_visible`, `all`, `title`, `screenshot`, `keyboard.press`, `mouse.wheel`, `wait_for_timeout`,
  `wait_for_selector`, `new_page`, `close`, `connect_over_cdp`, `launch_persistent_context`.
- Not awaited: `page.url`, `page.locator()`, `.first`, `.last`, `context.pages`, `browser.contexts`, `page.keyboard`.
- `time.sleep(x)` → `await asyncio.sleep(x)`.
- `input(p)` → `await asyncio.to_thread(input, p)`.
- Blocking voice GUI calls (`get_voice_command`, `show_plan_and_confirm`) → `await asyncio.to_thread(...)`. Butler calls stay as they are.

`ActionExecutor` (P1) takes a `PlaywrightDriver`. It exposes `page` (the current Playwright `Page`) and
`current_tab_name`; handlers keep their Playwright code, now awaited. `new_tab`/`switch_tab`/`close_tab` call the
driver (keep the legacy messages: `Tab '{name}' not found`; closing the current tab returns to `main`).
`analyze_page` and `get_current_context()` return `await driver.legacy_context()`.
Renames inside the moved code:
- `executor.current_page` → `executor.page`;
- `executor.tab_manager.tabs` → `executor.driver.list_tabs()`;
- `TabManager(context)` + `ActionExecutor(tab_manager, initial_page)` →
  `driver = PlaywrightDriver(context, initial_page, attached=is_connected, browser=browser)`, then
  `await driver.start()` and `executor = ActionExecutor(driver)`.
REPL commands in `main()`:
- `tabs`: `driver.list_tabs()` + `driver.get_tab_page(name)`;
- `new`: `await driver.new_tab()`;
- `screenshot`: write `await driver.screenshot()` to `screenshot_%H%M%S.png`;
- hacker mode: `await run_hacker_mode(driver.page, butler)`.
Session close: `tabs_closed = await driver.close()`, then the legacy prints and `cleanup_temp_dir()`.

`babas/__main__.py`: argparse with subcommands `cli` (the default when none is given) and
`serve [--host 127.0.0.1] [--port 8765] [--repl]`. `main()` calls `load_dotenv()` and then dispatches. Until P1.5,
`serve` may exit with `serve: implemented in P1.5`.

### [ ] P1.3 `PlaywrightDriver` (`babas/drivers/playwright_driver.py`)
```python
PAGE_SCRIPT = importlib.resources.files("babas.drivers").joinpath("page_script.js").read_text(encoding="utf-8")

class PlaywrightDriver(BrowserDriver):
    name = "playwright"
    def __init__(self, context: BrowserContext, initial_page: Page, *, attached: bool = False, browser: Browser | None = None): ...
```
- Tabs: a `dict[str, Page]` with the initial page as `"main"`. New default names are `tab_1`, `tab_2`, and so on;
  closing `"main"` is refused (returns `False`). Keep the legacy prints `   New tab: '{name}'` and `   Tab closed: '{name}'`.
  `page` property, `current_tab`, `list_tabs()`, `get_tab_page(name)`.
- `start()`: `await context.add_init_script(script=PAGE_SCRIPT)`.
- `_ensure(page)`: if `not await page.evaluate("() => !!window.__babas")`, run `await page.evaluate("() => {" + PAGE_SCRIPT + "\n}")`.
- `_call(cmd: dict)`: runs `_ensure`, then `r = await page.evaluate("c => window.__babas.handle(c)", cmd)`. If `not r["ok"]`,
  raise `DriverError(code, message, data)`; return `r.get("result")`.
- `get_page_state(highlight)` uses `_call({"op":"snapshot","highlight":highlight,"max_elements":250,"max_text":2000})`.
  The result goes through `PageState.model_validate` with `tab=current_tab`.
- `describe` → `op describe` → `Element`. `is_visible` → `op exists` → `visible`. `scroll`, `read_text` and `highlight`
  use the page ops of the same name. `select_option` uses `op select` with `authorized: True` and returns `selected`.
- `click`/`type_text`/`press_key` use native Playwright input (trusted events):
  - `selector` targets: `page.locator(selector).first` (Playwright syntax allowed).
  - `index`/`text` targets: `mark = await _call({"op":"mark","target":...})`, then
    `page.locator(f'[data-babas-mark="{mark["mark"]}"]')`, and `_call({"op":"unmark"})` in `finally`.
  - Calls: `click(timeout=5000)`, `fill(text, timeout=5000)`, `press(key)`; with no target, `page.keyboard.press(key)`.
  - Before typing, `describe` the target; if it has the `password` flag, raise `DriverError(PASSWORD_FIELD)`.
- `goto(url)`: `page.goto(url, wait_until="domcontentloaded", timeout=30000)`, then `wait_for_load_state("load", timeout=10000)`
  (ignore that timeout). `current_url()` returns `page.url`. `screenshot()` returns `await page.screenshot()`.
- Error mapping: Playwright `TimeoutError` → `DriverError(TIMEOUT)`; any other Playwright `Error` → `DriverError(INTERNAL, str(e))`.
- `legacy_context()`: the async `PageAnalyzer.get_page_summary(page)` dict (used only by the P1 agent; deleted in P2).
- `close() -> int`: close every BABAS tab page, then `browser.close()` if `attached`, otherwise `context.close()`.
  Returns the number of tabs closed. `cli.py` prints the legacy messages.
- The browser discovery, launch and CDP helpers keep their names and become `async` where they sleep or connect.

### [ ] P1.4 `ExtensionDriver` (`babas/drivers/extension_driver.py`)
`ExtensionDriver(bridge: BridgeServer)` maps every method to one bridge request (`docs/PROTOCOL.md` §1):
| method | request | notes |
|---|---|---|
| `start()` | `tab.info` | registers name `"main"` → that `tab_id` |
| `goto(url)` | `tab.goto {url}` | timeout 60 s |
| `current_url()` | `tab.info` | |
| `get_page_state(highlight)` | `page.state` | `PageState.model_validate`, with `tab` = current name |
| `describe(target)` | `page.describe {target}` | `Element.model_validate(payload["element"])` |
| `is_visible(target)` | `page.exists {target}` | `payload["visible"]` |
| `click`/`type_text`/`press_key`/`select_option`/`scroll`/`read_text`/`highlight` | `page.act {op,…}` | pass `confirmation_id` when given; return `select`→`selected`, `read`→`text` |
| `screenshot()` | `tab.screenshot` | base64-decode `png_base64`; timeout 20 s |
| `new_tab(name, url)` / `switch_tab` / `close_tab` | `tab.new` / `tab.switch` / `tab.close` | same name rules as `PlaywrightDriver` |
Serialize targets with `target.model_dump(exclude_none=True)`. The default timeout is 30 s.
